# Nym Technologies

> Nym Technologies SA builds Nym, open-source decentralized privacy infrastructure. Its flagship product NymVPN is a decentralized VPN built on the Nym mixnet — a multi-layer network of mix nodes that protects metadata, not just IP addresses, using the Sphinx packet format, cover traffic, and zero-knowledge ecash (zk-nyms). Nym publishes public infrastructure APIs plus Rust and TypeScript SDKs for routing traffic through the mixnet.

## APIs

- [Nym API](https://nym.com/docs/apis/introduction): Public validator / nym-api for querying mixnet infrastructure — bonded/described nodes, legacy mixnodes and gateways, node families, epochs, reward params, NYM supply, ecash signatures, chain and signer status. Base URL https://validator.nymtech.net/api
- [Node Status API](https://nym.com/docs/apis/introduction): Live node status, performance, and uptime telemetry. Base URL https://mainnet-node-status-api.nymtech.cc

## SDKs and packages

- [Rust SDK (nym-sdk)](https://crates.io/crates/nym-sdk): async mixnet client with AsyncRead/AsyncWrite streams
- [TypeScript SDK (@nymproject/sdk)](https://www.npmjs.com/package/@nymproject/sdk): browser-side mixnet client
- [@nymproject/mix-fetch](https://www.npmjs.com/package/@nymproject/mix-fetch): drop-in fetch() over the mixnet
- [@nymproject/contract-clients](https://www.npmjs.com/package/@nymproject/contract-clients): Nyx smart-contract clients
- [@nymproject/node-tester](https://www.npmjs.com/package/@nymproject/node-tester): WASM node routing tester
